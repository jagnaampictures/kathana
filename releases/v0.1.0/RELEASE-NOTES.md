## Overview

Kathana Beta v0.1.0 is the first public Beta release of Kathana, a creative writing application built to help writers shape ideas, develop stories, and bring them to life.

The Beta provides a desktop screenplay-writing environment with local project files, screenplay formatting, scene-based writing, and selected import and export workflows.

Kathana is designed around a clear principle:

> **Download is public. Trial is public. Account is identity. Screenplays remain local.**

This is an early public Beta. Users should maintain independent backups of important work and review imported or exported documents before relying on them for professional use.

## Core Principles

### Local-first screenplay storage

Kathana Beta is designed to keep screenplay projects on the user's computer.

The Beta does not provide cloud screenplay storage, automatic screenplay synchronisation, or an account-based screenplay library.

Native Kathana projects use the `.kathana` file extension.

Users are responsible for maintaining independent backups of important screenplay projects.

### Separate account system

Kathana uses email-based authentication for account identity and Beta access.

The account system is separate from the user's screenplay content. The normal writing workflow does not require screenplay contents to be uploaded to Kathana's account backend.

### Local trial

Kathana Beta provides a 14-day full-feature trial.

The trial state is maintained locally on the computer rather than requiring screenplay contents to be uploaded to a server.

After the trial expires, eligible account sign-in is required to continue editing.

Existing local screenplay files can still be opened and exported after the trial ends, subject to the application's access rules.

## Writing Environment

Kathana Beta includes the following writing capabilities:

- Screenplay writing and formatting
- Scene-based writing
- Scene controls
- Omitted scenes
- Dual dialogue
- Title pages
- Headers and footers
- Script preview
- Search
- Settings
- Light and dark themes
- Application menus
- Save As and reopen workflows
- Multiple windows
- Local backup and recovery features

Kathana also supports writing in Kannada and other Indian scripts, with script-aware text handling designed to preserve cursor movement and deletion for complex writing systems.

---

## Import and Export

The Beta supports selected document workflows, including:

- DOCX import
- Word export
- PDF export
- Fountain export

Import and export results should be reviewed before using the resulting document for a submission, production, publication, or other important purpose.

---

## Privacy and Data Handling

Kathana's architecture separates account information from screenplay content.

The Beta does not provide:

- Cloud screenplay storage
- Automatic screenplay synchronisation
- A server-side screenplay backup
- An account-based screenplay library

Using the same Kathana account on another computer does not automatically transfer local screenplay files to that computer.

For information about account data, authentication, support communications, third-party services, retention, and privacy rights, consult the published Privacy Policy.

---

## Authentication

The Beta uses email-based authentication with a six-digit verification code sent to the email address associated with the account.

Account services support identity, authentication, and Beta entitlement. They are not intended to serve as storage for screenplay projects.
